# Skier or IKEA-r?

A seven-question phone game: is the name on screen a cross-country ski racer or an IKEA product?

- `index.html` is the game source (also published as a Claude artifact).
- `docs/index.html` is the standalone copy GitHub Pages serves. Regenerate it with `./build.sh` after editing the game.

Skier names come from FIS World Cup fields and the FIS registers of active Swedish and Norwegian racers. IKEA names come from IKEA Canada's series list and Lars Petrus's IKEA Dictionary (lar5.com/ikea). Just for fun; not affiliated with FIS or IKEA.
